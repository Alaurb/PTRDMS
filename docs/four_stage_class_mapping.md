# Four-stage maturity-class mapping

The repository uses the four visual maturity stages in GH/T 1193-2021. The on-disk model labels are hyphenated only because they are folder-safe training names.

| Model output label | Repository display name | Manuscript term | Chinese term |
|---|---|---|---|
| `immature-period` | `immature` | immature period | 未熟期 |
| `green-maturity-period` | `green_mature` | green-maturity period | 绿熟期 |
| `discoloration-period` | `discoloration` | discoloration period | 转色期 |
| `maturity-period` | `mature` | maturity period | 成熟期 |

`unclassifiable` is a review disposition, not a deployed model class. It is excluded before all training and evaluation splits.
